Terminal Tricks

In this post, we share some handy terminal tricks:

1. Use Ctrl+R to search your command history.

2. Use pipes | to combine commands (not available in this demo).

3. Use wildcard patterns like *.md to match files (also not available here).

You can view this post in a rich mode using vim or nano commands.
